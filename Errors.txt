# CRITICAL FIX 1 — Ensure systemd Exists

Add in:

```text
conf/local.conf
```

```conf
DISTRO_FEATURES:append = " systemd"

VIRTUAL-RUNTIME_init_manager = "systemd"

IMAGE_INSTALL:append = " systemd"
```

Otherwise:

❌ `systemctl` may not work.

---

# CRITICAL FIX 2 — Auto Enable Services

Inside EVERY recipe add:

```bitbake
SYSTEMD_AUTO_ENABLE = "enable"
```

Example:

```bitbake
inherit systemd

SYSTEMD_SERVICE:${PN} = "hwmon-service.service"

SYSTEMD_AUTO_ENABLE = "enable"
```

Without this:

❌ services installed
❌ but not auto-started

---

# CRITICAL FIX 3 — Runtime File Race Condition

This code:

```cpp
std::ifstream sensorFile("/run/hwmon-temperature");
```

may fail initially because producer has not created file yet.

---

# FIX

Replace:

```cpp
getline(sensorFile, temperature);
```

with:

```cpp
if (sensorFile.is_open())
{
    getline(sensorFile, temperature);
}
else
{
    temperature = "0";
}
```

---

# CRITICAL FIX 4 — Create `/run` Safely

Add before writing:

```cpp
#include <filesystem>
```

and:

```cpp
std::filesystem::create_directories("/run");
```

Though `/run` usually exists in systemd systems.

---

# CRITICAL FIX 5 — Better Compile Flags

Replace:

```bitbake
${CXX} ${CXXFLAGS} file.cpp -o binary
```

with:

```bitbake
${CXX} ${CXXFLAGS} ${LDFLAGS} file.cpp -o binary
```

Production-safe linking.

---

# CRITICAL FIX 6 — Add Package Architecture

Inside recipes:

```bitbake
PACKAGE_ARCH = "${MACHINE_ARCH}"
```

Helpful for embedded firmware packaging.

---

# CRITICAL FIX 7 — Use C++17 for filesystem

Because:

```cpp
#include <filesystem>
```

needs C++17.

Add:

```bitbake
CXXFLAGS += "-std=c++17"
```

---

# RECOMMENDED FINAL RECIPE TEMPLATE

Use this pattern everywhere:

```bitbake
inherit systemd

SYSTEMD_SERVICE:${PN} = "hwmon-service.service"

SYSTEMD_AUTO_ENABLE = "enable"

CXXFLAGS += "-std=c++17"

do_compile() {

    ${CXX} ${CXXFLAGS} ${LDFLAGS} \
        hwmon-service.cpp \
        -o hwmon-service
}
```
